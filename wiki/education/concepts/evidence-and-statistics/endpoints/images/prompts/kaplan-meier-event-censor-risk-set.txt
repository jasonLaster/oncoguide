Creation method and reproduction
This is a standard plotting artifact made by render-chart.py with Matplotlib 3.10.8, not an image-generation tool output. No raster reconstruction or synthetic source figure is involved.
Portable source bundle: images/source/kaplan-meier-event-censor-risk-set/ beside the canonical owner contains render-chart.py, requirements.txt, chart-data.json, chart-coordinates.json, reproduction-environment.json and render-receipt.json.
To reproduce on a host with Python 3 and a venv, from that source directory:
  python3 -m venv .venv
  .venv/bin/python -m pip install -r requirements.txt
  .venv/bin/python render-chart.py --output-dir reproducibility-output
Compare generated SVG/data/coordinates SHA256 values to the reviewed manifest before replacing accepted assets. Package installation is from the known PyPI registry.
Exact typography was measured with Arial on macOS; reproduction-environment.json records the font path/hash. The SVG declares editable Arial text with a sans-serif fallback. Hosts lacking the same font can vary typography, so do not claim byte-exact reproduction or delivered font sizes without checking actual results. Do not distribute an unlicensed font merely to match the hash. On the recorded author host, both author and independent repeated renders reproduce all five output files byte-for-byte.
Determinism: metadata date omitted; fixed SVG hash salt; no path simplification. Palette-derived marker IDs can differ between themes; every reference resolves and geometry/words match after canonical ID/palette comparison.

Caption and inference guards
Censoring is incomplete follow-up, not an event or proof of permanent event freedom. The group estimate does not supply the censored individual's missing month 3 outcome. The original table, answered practice and censoring/competing-risk caveats remain in the owner unchanged. This chart does not certify censoring assumptions, clinical endpoint suitability, competing-risk equivalence, expert/learner acceptance or benefit.
